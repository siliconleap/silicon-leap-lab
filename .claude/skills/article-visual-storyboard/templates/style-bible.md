# 视觉风格定义

> 这份文件是**可替换的配置**，不是 skill 的一部分。一组图开画前先定它，
> 定完不要中途改——画到第五张再改风格，前四张全得重来。
>
> 下面是「手绘线稿 · 深色」这一版，来自 2026-08 的实测。要换风格就整份换掉。

## 颜色语义

同一个意思在整组图里必须同色，不许按好看换。

| 色值 | 语义 | 用在 |
| --- | --- | --- |
| `#c3c2b7` | 主体、中性对象 | 文档、容器、人物、设备的轮廓 |
| `#898781` | 次要、背景、已弱化 | 散落物、辅助标注、注释文字 |
| `#ffffff` | 强调文字 | 嵌入的原话正文 |
| `#3987e5` | 流动、处理、AI 参与 | 箭头、连接线、AI 相关元素 |
| `#0ca30c` | 通过、完成、成立 | 勾、成功标记、走完的进度 |
| `#fab219` | 停滞、返工、警示 | 打转的循环、来回的箭头 |
| `#d03b3b` | 失败、缺失、禁止 | 叉、禁止符、没做到的部分 |

状态色**必须配形状**（勾/叉/禁止符），不能只靠颜色区分——色盲用户和压缩后
的视频都分不出来。

## 线条

- 线宽 4–9px（1920 画布）。主体 6–7，次要 4–5，强调 8–9
- `stroke-linecap="round"` `stroke-linejoin="round"`，一律圆头圆角
- `fill="none"` 为主。实心只用于小圆点、光标、小色块

## 手绘质感

```xml
<filter id="hand" x="-10%" y="-10%" width="120%" height="120%">
  <feTurbulence type="fractalNoise" baseFrequency="0.016" numOctaves="3" seed="5" result="n"/>
  <feDisplacementMap in="SourceGraphic" in2="n" scale="3.2"
                     xChannelSelector="R" yChannelSelector="G"/>
</filter>
```

- `scale` 2.5–4。再大线条会断，再小看不出手绘感
- 每张图换一个 `seed`，否则同一处抖动会重复，串成视频看得出来
- **只加在图形分组上。`<text>` 一律放在 filter 之外**，否则文字扭糊

## 字体与字号

| 用途 | 字体 | 字号（1920 画布） |
| --- | --- | --- |
| 嵌入的原话 | `-apple-system, 'PingFang SC', sans-serif` | 27–34 |
| 终端 / 代码 / 时间戳 | `'SF Mono', Menlo, monospace` | 20–27 |
| 图内标注 | `-apple-system, 'PingFang SC', sans-serif` | 26–30 |
| 强调批注 | 同上，配 `#d03b3b` | 26 |

最小 26px。中文标注一行不超过 14 字。

## 常用 icon 语汇

同一个概念反复出现时用同一个画法，读者第二次见就认识了：

| 概念 | 画法 |
| --- | --- |
| 文档 / 稿件 | 竖长矩形，右上角折角 |
| 一叠文件 | 三张错位叠放，后两张 opacity 0.5 / 0.28 |
| 目录 / 容器 | 带凸起标签的文件夹轮廓 |
| AI / 模型 | 方形芯片 + 四周引脚，中心一个四角星 |
| 人 | 圆头 + 半圆肩，手臂用单线 |
| 终端窗口 | 圆角矩形 + 顶栏三个圆点（红黄绿），内部深一档 `#111110` |
| 散乱 / 未整理 | 5–8 个小矩形随机旋转 ±14°，用次要色 |
| 流程推进 | 直箭头，`#3987e5` |
| 打转 / 返工 | 闭合的环形箭头，`#fab219` |
| 中断 / 未完成 | 虚线 `stroke-dasharray="26 26"` |

## 构图

- 主体占画面 **70–80%**，四周留白控制在 10% 左右
- 横版按「左 → 中 → 右」读，对应「之前 → 过程 → 之后」
- 一张图最多三个视觉区块，超过就拆
- 嵌真实文字的容器（终端窗口）放在视线终点，通常是右侧或右下

## 反面清单

第一版三张废稿的死因，别再犯：

- ❌ 元素小、散、四周大片黑 —— 视频里就是「空」
- ❌ 只有图形没有文字 —— 读者猜不出在讲什么
- ❌ 一张图塞三个概念 —— 没有重点
- ❌ 用抽象几何表达具体事件 —— 「一个圆圈代表卡住」没人看得懂，不如画一条走不完的进度
