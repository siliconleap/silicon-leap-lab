来源优先级：真实截图 > 数据卡 > 结构图 > 示意图。
确定性的卡片出 SVG 源到 `assets/`；需要真实截图的列进缺口，不要用示意图冒充。

## 全局规格

| 项 | 值 |
| --- | --- |
| 尺寸 | 1080 × 1440（3:4 竖屏） |
| 安全边距 | 四周 ≥ 80px |
| 底色 | `#1a1a19` |
| 文字 | 主 `#ffffff` / 次 `#c3c2b7` / 弱 `#898781` |
| 状态色 | 通过 `#0ca30c` · 警告 `#fab219` · 严重 `#ec835a` · 失败 `#d03b3b` |
| 分类色 | 依次 `#3987e5` `#d95926` `#199e70`，固定顺序不循环 |
| 字体 | 系统 sans，不用衬线或展示体 |

硬规则：状态色必配图标与文字；文字不穿数据色；每张卡只有一个 hero 元素；大数字用比例数字。
