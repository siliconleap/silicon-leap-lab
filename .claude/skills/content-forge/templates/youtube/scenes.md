## 格式约定

`build-video.py` 直接解析这个文件，字段名和分隔符不能改：

- 每个 scene 以 `### S<两位数> · <标题>` 开头，编号连续
- `**旁白：**` 下一段是要念的文本，可多行；空行结束
- `**画面：**` 一行，取值见下
- `**证据级别：**` 一行，四选一
- `**B-roll：**` 一行，无则写「无」

旁白字段一份三用：TTS 的输入、字幕的内容、人审的对象。不要在旁白里写
括号说明或舞台指示——它们会被念出来。

## 证据级别

| 级别 | 什么算 | 画面上要不要标 |
| --- | --- | --- |
| 一手 | 会话记录、git 历史、文件 diff、当时的截图 | 不标 |
| 复现 | 事后补录的终端操作 | 标「复现」 |
| 示意 | 生成的 B-roll、结构示意图 | 标「示意」 |
| 缺 | 没有素材，也没决定怎么补 | 不能进片，先留着 |

标注是硬要求。级别为「缺」的 scene，`build-video.py` 会拒绝构建。

## 画面取值

- 图片路径——`drafts/*/assets/*.png`，静态铺满该 scene 时长
- 视频路径——B-roll `.mp4`，比旁白短则定格末帧，长则截断
- `记录:<文件>@<时间戳>`——会话记录渲染，由 agent 先出 HTML 再 `render.sh`
