## 格式约定

这个文件会被机器解析，字段名和分隔符不能改：

- 每个 scene 以 `### S<两位数> · <标题>` 开头，编号连续
- `**旁白：**` 下一段是要念的文本，可多行；空行结束
- `**画面：**` 一行，取值见下
- `**证据级别：**` 一行，四选一
- `**B-roll：**` 一行，无则写「无」
- `**图层：**` 分层渲染时填，见下；走轻量通道则写「无」

scene 编号要跟 `project.json` 里的 `scenes[].id` 一一对应——配音时
`--scene-ids` 按顺序把旁白段落绑到 scene 上，对不上就回填不了时间轴。

旁白字段一份三用：TTS 的输入、字幕的内容、人审的对象。不要在旁白里写
括号说明或舞台指示——它们会被念出来。

## 证据级别

| 级别 | 什么算 | 画面上要不要标 |
| --- | --- | --- |
| 一手 | 会话记录、git 历史、文件 diff、当时的截图 | 不标 |
| 复现 | 事后补录的终端操作 | 标「复现」 |
| 示意 | 生成的 B-roll、结构示意图 | 标「示意」 |
| 缺 | 没有素材，也没决定怎么补 | 不能进片，先留着 |

标注是硬要求。级别为「缺」的 scene，`build-video.py` 会拒绝构建。

## 画面取值

- 图片路径——`drafts/*/assets/*.png`，静态铺满该 scene 时长
- 视频路径——B-roll `.mp4`，比旁白短则定格末帧，长则截断
- `记录:<文件>@<时间戳>`——会话记录渲染，由 agent 先出 HTML 再 `render.sh`

## 图层

分层渲染时，每个 scene 列出它的图层，一行一个：

```
**图层：**
- bg-desk / background — 无
- 人物 / primary — reveal-left
- 便签 / secondary — settle-drop
- 手 / foreground — push-through
```

格式是 `素材名 / 角色 — 运动模板`。角色五选一：`background`、`tertiary`、
`secondary`、`primary`、`foreground`。运动模板从
`editorial-video/references/motion-templates.json` 里挑，不要自己编曲线——
挑哪个是叙事判断，曲线数值不是。没有运动写「无」。

规矩：

- **背景不进图层列表的运动**。背景是环境板，动的是 camera 不是它。
- **要动、要变状态、要穿过前后景的元素必须单独一层。** 一张画好的合成图再
  好看也只能当参考，不能当可发布的分层 scene。
- **相邻两个 scene 不要用同一个模板。** audit 会报，而且看起来确实机械。
- 一个 hero scene 常见 3-7 层，但这不是配额。这一拍只有一个东西在动，就一层。
