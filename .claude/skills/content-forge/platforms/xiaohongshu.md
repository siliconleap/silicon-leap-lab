# 小红书

## Role

图文平台内容包。目标是让用户在第一屏就知道实验反直觉点，并愿意点开看证据。

## Emphasis

- 封面、标题、前三行优先。
- 第一屏的冲突必须包含实验对象。先让读者知道在测什么，再写片 A、片 B、QA、返工或数字，不把内部代号当上下文。
- 用具体数字、失败次数、对比结果建立可信度。
- 短句、短段落、强排版，可扫读。
- 配图必须服务信息，不做纯装饰。
- 评论区 CTA 指向完整数据、GitHub 或主页。

## Layout Rules

- 标题 20 字以内，给 3-5 个备选。
- 第一段先用一两句交代实验对象和读者处境，再给反直觉发现或实验结果；不要把背景删到只剩内部代号。
- 正文每段 1-3 行。
- 至少给 5 个标签，混合大词、垂直词、实验对象词。
- 配图脚本必须说明每张图的目的和画面。

## 语气：治枯燥的不是加规则，是看示范

只写「短句、可扫读」，照做就会得到机械的三段列表。同一份素材，两种开头：

**枯燥（不要这样）**

> 准备把仓库推上 GitHub，扫了一遍敏感信息，发现两处泄露。
>
> **结果：**
> - 流水线能跑，平台工具依赖 0
> - 12 个 skill 文件、4 个平台配置

陈述完事实就转进列表。没有处境，没有当时的反应，数字没有参照系。读者知道发生了什么，但没有理由往下读。

**有场景（这样写）**

> git push 之前我又扫了一遍。
>
> 这个仓库三分钟前我才检查过，工作区干干净净——没有密码，没有密钥，没有绝对路径。
>
> 然后我查了 git 历史。
>
> 两处。一处是提交作者，一处藏在软链接里。

区别不在形容词，在四件事：

- **给处境**——push 之前、三分钟前刚查过
- **有节奏**——「然后我查了 git 历史」独占一行，制造停顿
- **数字带参照**——不是「发现 2 处」，是「我以为干净的仓库里有 2 处」
- **留钩子**——藏在软链接里，想知道就得往下看

### 边界：治枯燥不等于加戏

禁夸张营销词和空泛感叹这条不变。能用的是场景、节奏、具体细节；不能用的是：

| 不要 | 因为 |
| --- | --- |
| 「震惊」「太可怕了」「99% 的人不知道」 | 空泛，与可信实践者定位相反 |
| 「一键搞定」「效率提升 10 倍」 | 没有数据支撑的收益承诺 |
| 「家人们」「姐妹们」 | 与技术读者的关系不符 |
| 结尾「你学会了吗」 | 教程腔 |

emoji 只作**段落路标**：每段开头最多一个，全篇 6-10 个，不装饰句中、不连着放。

平台爆款笔记平均 30+ 个 emoji，这里刻意压到三分之一。理由不是审美——每多一个表情，可信度就掉一点，而这个账号押的就是可信度。够用即可，不追平台平均值。

## 视觉资产

图不是配图，是主体。每张图必须能脱离正文独立看懂。

| 项 | 值 |
| --- | --- |
| 比例 / 尺寸 | 3:4 竖屏，1080 × 1440 |
| 底色 | 深色 `#1a1a19`（终端质感，手机夜读友好） |
| 文字 | 主 `#ffffff` / 次 `#c3c2b7` / 弱 `#898781` |
| 状态色 | 通过 `#0ca30c` · 警告 `#fab219` · 严重 `#ec835a` · 失败 `#d03b3b` |
| 分类色 | 依次取 `#3987e5` `#d95926` `#199e70`，**固定顺序，不循环** |
| 字体 | 系统 sans，不用衬线或展示体 |

**硬规则**（来自 dataviz 规范，不是审美偏好）

- 状态色**必须配图标和文字**，颜色不单独承载含义
- 文字不穿数据色；标识靠文字旁边的色块
- 每张卡**只有一个** hero 数字，其余降级
- 大数字用比例数字；只有需要竖向对齐的表格列才用等宽数字
- 超过三个并列类别就合并成「其他」或拆成两张卡，不要新造颜色

**来源优先级**：真实截图 > 数据卡 > 结构图 > 示意图。

截图缺失可以重演补拍，但**重演必须与 git 历史一致，不许摆拍伪造报错或时间线**。

**生成方式**：封面卡和数据卡由 agent 直接出图。写 HTML 源到 `drafts/xiaohongshu/assets/`（带 `<meta name="render-size" content="1080x1440">`），再跑 `scripts/render.sh` 渲染成 PNG。HTML 进 git、可 diff、改图重渲染；PNG 是产物。真实截图不生成，列进缺口清单。

**图里也要脱敏。** 讲泄露的封面自己带着真名、邮箱或 `/Users/<真实用户名>/`，比正文泄露更难挽回——图会被转发，改不了。一律用 `<用户名>` `<个人邮箱>` 这类占位符。

## Acceptance Checklist

- 第一屏有具体结论或冲突。
- 开头有处境和节奏，不是「陈述事实 + 列表」。
- 没有教程腔、夸张营销词或空泛感叹。
- 有封面图 brief。
- 有 4-6 张轮播图 brief，每张含布局、文案、字号层级、色值、数据来源。
- 数据卡遵守 hero 数字唯一、状态色配图标与文字。
- 确定性的卡片出了 SVG 源文件；缺的真实截图列进缺口清单，不假装齐全。
- 可以交给小红书发布 skill 做排版/发布，但本 skill 不发布。
