# 小红书

## Role

图文平台内容包。目标是让用户在第一屏就知道实验反直觉点，并愿意点开看证据。

## Emphasis

- 封面、标题、前三行优先。
- 用具体数字、失败次数、对比结果建立可信度。
- 短句、短段落、强排版，可扫读。
- 配图必须服务信息，不做纯装饰。
- 评论区 CTA 指向完整数据、GitHub 或主页。

## Layout Rules

- 标题 20 字以内，给 3-5 个备选。
- 第一段不铺垫，直接给反直觉发现或实验结果。
- 正文每段 1-3 行。
- 至少给 5 个标签，混合大词、垂直词、实验对象词。
- 配图脚本必须说明每张图的目的和画面。

## Acceptance Checklist

- 第一屏有具体结论或冲突。
- 有封面图 brief。
- 有 4-6 张轮播图 brief，优先真实截图和数据图。
- 没有教程腔、夸张营销词或空泛感叹。
- 可以交给小红书发布 skill 做排版/发布，但本 skill 不发布。
