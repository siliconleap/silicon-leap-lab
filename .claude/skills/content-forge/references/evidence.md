# 事实与证据

## 蒸馏

读取 README、plan、notes、data、recordings、会话时间线、content-outline 和 Artifacts。数字只来自 README Data 或 `data/`；缺失写待补，不估算。

从原始记录建立内容简报：背景与问题、读者处境、关键事实、共通困难、实践清单、人工投入与发布状态、超出预期、结论边界、作者确认。

## 选择过程素材

保留：判断转向、犹豫或批准、自我诊断、卡点第一次出现。跳过无关环境配置和纯操作命令。引用会话记录时给文件和时间戳；可以润色措辞，不能合并或添加意思。

困难分为两类：

- **临时**：解法与被测对象无关，换环境即可消失。留在记录，不进正文。
- **共通**：由技术路线的性质导致，读者明天照做仍会撞上。进正文。

写叙事前先看耗时分布。耗时最多的环节应在正文占相称篇幅，或明确说明为什么不展开。

## 发布状态

明确区分：已公开可看、可复制改造、内部可用但未开放、待人工发布。不要用文件路径或工具名替代状态说明。
