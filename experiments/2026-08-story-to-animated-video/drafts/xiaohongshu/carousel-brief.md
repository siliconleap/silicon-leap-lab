# 小红书配图脚本

## 全局规格

| 项 | 值 |
| --- | --- |
| 尺寸 | 1080 × 1440（3:4） |
| 安全边距 | 四周 ≥ 80px |
| 底色 | `#1a1a19` |
| 文字 | 主 `#ffffff` / 次 `#c3c2b7` / 弱 `#898781` |
| 状态色 | 通过 `#0ca30c` · 警告 `#fab219` · 失败 `#d03b3b` |
| 分类色 | `#3987e5` `#d95926` `#199e70` |
| 字体 | 系统 sans |

状态色配图标和文字。每张卡只有一个 hero 元素。数字全部来自 README Data。
